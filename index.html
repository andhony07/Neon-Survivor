Evolutions: Rapid Fire x2 + Heavy Rounds = Minigun · Multishot + Explosive Ammo x2 = Cluster Cannon · Heavy Rounds x2 + Piercing = Railgun. A gold card appears when you qualify.

Builds: upgrades are tagged CRIT, BLAST or TANK. Take 3 of one tag for a synergy perk, 5 for a bigger one. Mix CRIT+BLAST or TANK+BLAST for hybrid perks.

Pilots: pick one when you start a run. Each leans into a build (Ace = crit, Blaze = blast, Bastion = tank, Ghost = dash damage). Unlock them with Cores.

Cores: every run earns Cores (score, waves survived, bosses killed), even if you quit from the pause menu. Spend them in Upgrades for bonuses that last forever.

Kill enemies, grab the cyan XP gems, pick an upgrade each level. A boss arrives every 5 waves.
